# America: A Short History

A five-minute documentary about American history, from the First Peoples to today. Everything in it is generated by `build.py`. It uses no stock footage, recorded voice or downloaded music.

| Part | Source |
| --- | --- |
| Narration | Festival's offline HTS voice (`cmu_us_slt_arctic_hts`), with light EQ and room reverb |
| Score | String-pad chords and timpani at each chapter card, synthesized with NumPy. The music ducks under the narration |
| Maps | `data/states-albers-10m.json` (US Census) and `data/land-50m.json` (Natural Earth), from the ISC-licensed [us-atlas](https://github.com/topojson/us-atlas) and [world-atlas](https://github.com/topojson/world-atlas) |
| Charts | Census population counts 1790–2020; Depression-era unemployment (Lebergott series) |
| Look | EB Garamond type, parchment and film-grain textures, a sepia grade that fades to color in later chapters, slow camera push-ins |

## Chapters

The film opens with a title sequence and ends with an epilogue. In between are ten chapters:

1. The First Peoples
2. Two Worlds Collide
3. Revolution
4. We the People
5. Westward
6. A House Divided
7. Rails, Steel & Ballots
8. Depression & War
9. Freedom Now
10. A New Century

## Build

```bash
sudo apt-get install festival festvox-us-slt-hts fonts-ebgaramond ffmpeg
pip install numpy pillow
python3 documentary/build.py                  # -> american_history.mp4 + .srt
python3 documentary/build.py --stills 60 150  # preview single frames into build/
```

To change the script, edit the `lines` of a scene in `SCENES`. The timeline re-flows to match the new narration. Each scene's `panels` list decides which visual is on screen for each narrated sentence.
